# Jogi Gana Sai Surya - Portfolio

Static portfolio site (HTML, CSS, JavaScript). No build step needed.

## Files
- index.html - page content
- style.css - styles (light and dark themes)
- script.js - dark mode toggle
- assets/photo.jpg - profile photo
- assets/resume.pdf - resume used by the Download resume button

## Deploy on GitHub Pages
1. Create a repository (for example `portfolio`) and upload all files, keeping the `assets` folder.
2. Go to Settings > Pages.
3. Under Build and deployment, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Your site will be live at `https://Gana9989.github.io/portfolio/` after a minute or two.
